# Сборка на офлайн-ПК (закрытая сеть)

Рабочий ПК в закрытой сети без интернета, поэтому Maven не может докачивать
зависимости из центрального репозитория. Есть три пути.

## Вариант 1 (быстрый) — готовый архив репозитория
Взять присланный `offline-m2.tgz` (собран под этот `backend/pom.xml`), распаковать
рядом с проектом и собирать офлайн:
```
tar xzf offline-m2.tgz
cd backend
mvn -o -Dmaven.repo.local=../offline-m2 clean package
```
Либо влить артефакты в основной локальный репозиторий:
```
cp -rn offline-m2/* ~/.m2/repository/
cd backend && mvn -o clean package
```

## Вариант 2 — собрать архив самому на ПК с интернетом
```
bash scripts/build-offline-repo.sh      # создаст offline-m2.tgz
```
Перенести `offline-m2.tgz` флешкой и дальше как в варианте 1.

## Вариант 3 — сверка того, что уже есть
Снять инвентаризацию локального репозитория и переслать список:
```
bash scripts/m2-inventory.sh > m2-inventory.txt
```
По списку видно, каких артефактов не хватает — их можно догрузить точечно.

Полный перечень нужных зависимостей — `scripts/required-dependencies.txt`.

Зависимости привязаны к Spring Boot 3.2.1 (parent) и Java 17 — версии в `pom.xml`
менять не нужно, иначе набор артефактов в архиве перестанет совпадать.
